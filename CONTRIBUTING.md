# Contributing

This repository is maintained by neuland AI AG for customers of the Neuland AI
Hub. External pull requests are not accepted.

To report a problem, open a GitHub issue with the SDK version, the language,
and a minimal reproduction. For security matters, see [SECURITY.md](SECURITY.md).

Maintainers: see [MAINTAINING.md](MAINTAINING.md). The `python/sdk/` and
`nodejs/sdk/` folders are generated and are not edited by hand.
