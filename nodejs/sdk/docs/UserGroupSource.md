# UserGroupSource

Origin of a user group and its membership.  MANUAL groups are managed by hand in the HUB; EXTERNAL groups are synced from an identity provider (e.g. Entra, Keycloak).

## Enum

* `manual` (value: `'manual'`)

* `external` (value: `'external'`)
