# Security

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report privately through GitHub's
[private vulnerability reporting](https://github.com/neulandAI/neuland-ai-hub-sdk-sample/security/advisories/new) for this
repository. If that is unavailable, email **hello@neuland.ai** with
"Security" in the subject.

Include what you found, how to reproduce it, and the affected SDK version.

## What to expect

- Acknowledgement within 3 business days.
- A status update at least every 14 days until the issue is resolved.
- Credit in the release notes if you want it.

## Scope

This repository contains the generated Hub API clients, sample backends, and
docs. Issues in the Neuland AI Hub platform itself can be reported through the
same channel and will be routed to the right team.
