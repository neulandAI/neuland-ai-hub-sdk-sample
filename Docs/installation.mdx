description: "Install the Neuland AI Hub SDK."
---

The SDK is generated from the OpenAPI spec with the OpenAPI Generator, so the
method names and models mirror the [API Reference](/api-reference) exactly.

<Note>
  Replace the package name and version below with your published package once it
  is available.
</Note>

<CodeGroup>

```bash Python
pip install neuland-nimbus
```

```bash TypeScript
npm install @neuland/nimbus
```

</CodeGroup>

## Requirements

- A base URL: `https://api.your-domain.com`
- An access token or API key — see [Authentication](/authentication).

Continue to [Usage](/sdk/usage).
