## 1. Get a token

See [Authentication](/authentication). For a quick test, log in:

```bash
TOKEN=$(curl -s -X POST https://api.your-domain.com/auth/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=you@example.com&password=••••••••" | jq -r .access_token)
```

## 2. Call an endpoint

Use the token as a bearer token:

```bash
curl https://api.your-domain.com/users/me \
  -H "Authorization: Bearer $TOKEN"
```

## 3. Explore

Every endpoint, with parameters, schemas, and a live "Try it" playground, is in
the [API Reference](/api-reference) tab. Prefer a typed client? Head to the
