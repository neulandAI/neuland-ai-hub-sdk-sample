### Was ist das Deep Search Tool?

Das Deep Search Tool basiert ebenfalls auf Perplexity und ist für besonders umfangreiche und analytische Recherchen konzipiert. Es eignet sich vor allem für komplexe Fragestellungen wie Marktanalysen, Wettbewerbsvergleiche oder strukturierte Hintergrundrecherchen. Im Gegensatz zur schnellen Web-Suche verarbeitet Deep Search größere Informationsmengen und erstellt daraus eine zusammenhängende Analyse. Je nach Umfang der Anfrage kann die Bearbeitung mehrere Minuten dauern.

### So nutzen Sie das Deep Search Tool

1. Starten Sie einen neuen Chat.
2. Wählen Sie das Deep Search Tool aus, indem Sie es anklicken.
3. Formulieren Sie Ihre detaillierte Anfrage (z.B. „Vergleiche die Marktanteile der Top 5 Anbieter für CloudLösungen in Europa 2025“) im Chat und senden Sie die Anfrage ab.
4. Das System führt eine mehrstufige Recherche durch und erstellt anschließend eine strukturierte Auswertung.

### Beispiel – Marktanalyse

**Prompt:** „Erstelle eine Marktanalyse zu den führenden Anbietern von KI-Software für den Mittelstand in Deutschland 2026.“

**Antwort (Beispielauszug):** Die führenden Anbieter von KI-Software für den Mittelstand in Deutschland 2026 sind: Anbieter A, Anbieter B, Anbieter C. Marktanteile, Stärken/Schwächen und aktuelle Entwicklungen werden im Detail analysiert. \[Weitere Details folgen nach Abschluss der Analyse.\]

<Tip>
  **Hinweise zur Nutzung**

  Deep Search eignet sich für umfangreiche, analytische Fragestellungen. Die Bearbeitung kann je nach Recherche Umfang auch bis zu 20 Minuten dauern. Nach Abschluss der Analyse können Sie das Tool wieder abwählen, um weitere Recherche-Anfragen zu vermeiden.
</Tip>

<Info>
  **Zusammenfassung & Best Practices**

  - Nutzen Sie Web-Search für schnelle, aktuelle Informationen aus dem Internet.
  - Verwenden Sie Deep Search für tiefgehende Analysen und Vergleiche.
  - Achten Sie bei beiden Tools auf den Schutz sensibler Daten.
  - Formulieren Sie Ihre Anfragen präzise und geben Sie Zusatzwünsche (z.B. ausführlich, mit URL) direkt im Prompt an.
</Info>
