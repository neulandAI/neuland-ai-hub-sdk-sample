The Node SDK is published on npm as `neuland-hub-sdk`. It ships TypeScript
types and works with CommonJS and ES modules.

## Install

```bash
npm install neuland-hub-sdk
```

<Note>
  Releases are tagged `sdk-v<version>` in the
  [GitHub repository](https://github.com/neulandAI/neuland-ai-hub-sdk-sample).
  To build from source instead, clone it, then `cd nodejs/sdk && npm ci && npm run build`.
</Note>

## Requirements

- Node.js 18+
- A base URL for your Hub (for example `https://api.your-domain.com`)
- An API key (sent in the `X-API-KEY` header) — see [Quickstart](/guides/quickstart).

Continue to [Usage](/sdk/node/usage).
