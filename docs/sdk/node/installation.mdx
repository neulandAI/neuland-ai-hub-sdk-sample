The Node SDK lives in the `nodejs/sdk` subdirectory of the GitHub repository.
npm can't install a git **subdirectory** natively, so use one of the methods
below.

## Authenticate to GitHub

The repository is private, so installing needs GitHub access — add your SSH key
to GitHub, or use a personal access token (`~/.netrc` for local, `GITHUB_TOKEN`
in the URL for CI). See the [Python guide](/sdk/python/installation) for the
`~/.netrc` snippet; the same credentials apply here.

## Install

<Tabs>
  <Tab title="gitpkg (recommended)">
    Install the subdirectory directly via [gitpkg](https://gitpkg.vercel.app):

    ```bash
    npm install "https://gitpkg.vercel.app/neulandAI/neuland-ai-hub-sdk-sample/nodejs/sdk?dev"
    ```
  </Tab>
  <Tab title="Local clone">
    Clone, build, then install from the local path:

    ```bash
    git clone git@github.com:neulandAI/neuland-ai-hub-sdk-sample.git
    cd neuland-ai-hub-sdk-sample/nodejs/sdk && npm install && npm run build
    # then in your project:
    npm install /absolute/path/to/neuland-ai-hub-sdk-sample/nodejs/sdk
    ```
  </Tab>
</Tabs>

## Requirements

- Node.js 18+
- A base URL for your Hub (for example `https://api.your-domain.com`)
- An API key (sent in the `X-API-KEY` header) — see [Authentication](/guides/authentication).
