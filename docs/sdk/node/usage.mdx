## Configure the client

```typescript
import { Configuration, User } from "neuland-hub-sdk";

const configuration = new Configuration({
  basePath: "https://api.your-domain.com",
  apiKey: "ak_prod_v1.<key_id>.<secret>", // sent as X-API-KEY
});
```

## Make a request

Each API tag (for example `Alert`, `Chat`, `User`) becomes a client class, and
each endpoint's `operationId` becomes a method on it. The exact names are listed
under [API Methods](/sdk/node/reference/endpoints/User).

```typescript
const api = new User(configuration);

const { data } = await api.usersGetMyself();
console.log(data);
```

<Note>
  The per-endpoint and per-model reference pages in this section are generated
  directly from the SDK on every release, so they always match the installed
  package.
</Note>

## Read data with Query

The Hub's read-only `/query/<resource>` endpoint returns your chats, messages,
assistants, documents and more using PostgREST filters. Pass them as axios
`params`:

```ts
const { data: chats } = await new Query(config).queryQuery("chats", undefined, {
  params: { select: "id,name", order: "updated_at.desc", limit: 10 },
});
```

Ready-made recipes for the common cases are in
[Read data with Query](/guides/query).
