## Configure the client

```python
import neuland_hub_sdk

configuration = neuland_hub_sdk.Configuration(
    host="https://api.your-domain.com",
)
configuration.api_key["APIKeyHeader"] = "ak_prod_v1.<key_id>.<secret>"  # sent as X-API-KEY
```

## Make a request

Each API tag (for example `Alert`, `Chat`, `User`) becomes a client class, and
each endpoint's `operationId` becomes a method on it. The exact names are listed
under [API Methods](/sdk/python/reference/endpoints/User).

```python
with neuland_hub_sdk.ApiClient(configuration) as api_client:
    api_instance = neuland_hub_sdk.User(api_client)
    me = api_instance.users_get_myself()
    print(me)
```

<Note>
  The per-endpoint and per-model reference pages in this section are generated
  directly from the SDK on every release, so they always match the installed
  package.
</Note>

## Read data with Query

The Hub's read-only `/query/<resource>` endpoint returns your chats, messages,
assistants, documents and more using PostgREST filters. The generated
`Query` class only takes the resource name, so pass filters through the
client's request builder:

```python
method, url, headers, body, post = api_client.param_serialize(
    "GET", "/query/chats",
    query_params=[("select", "id,name"), ("order", "updated_at.desc"), ("limit", 10)],
    auth_settings=["APIKeyHeader"],
)
response = api_client.call_api(method, url, header_params=headers)
response.read()
chats = json.loads(response.data)
```

Ready-made recipes for the common cases are in
[Read data with Query](/guides/query).
