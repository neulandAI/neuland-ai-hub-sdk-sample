---

The Python SDK is published on PyPI as `neuland-hub-sdk`.

## Install

```bash
pip install neuland-hub-sdk
```

Or pin it in `requirements.txt`:

```
neuland-hub-sdk==1.2.1
```

<Note>
  Releases are tagged `sdk-v<version>` in the
  [GitHub repository](https://github.com/neulandAI/neuland-ai-hub-sdk-sample).
  To install from source instead, clone it and run `pip install ./python/sdk`.
</Note>

## Requirements

- Python 3.9+
- A base URL for your Hub (for example `https://api.your-domain.com`)
- An API key (sent in the `X-API-KEY` header) — see [Quickstart](/guides/quickstart).

Continue to [Usage](/sdk/python/usage).
