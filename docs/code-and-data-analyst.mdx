### Was ist der Code & Data Analyst?

Mit dem Code & Data Analyst können Sie im neuland.ai HUB Programm-Code und Daten direkt im Chat verwenden, analysieren und weiterverarbeiten. Das Tool unterstützt Sie dabei, Inhalte aus Dateien oder Texten auszuwerten und daraus strukturierte Ergebnisse zu erzeugen – beispielsweise Tabellen, Diagramme oder exportierbare Dateien.

Dadurch lassen sich Datenanalysen und einfache Auswertungen direkt innerhalb des Chats durchführen, ohne externe Anwendungen nutzen zu müssen.

Typische Einsatzfelder sind:

- Analyse von Daten aus hochgeladenen Dateien
- Strukturierung und Aufbereitung von Informationen
- Erstellung von Tabellen oder Diagrammen aus Datensätzen
- Generierung von exportierbaren Dateien aus KI-Ergebnissen

Die gesamte Verarbeitung erfolgt direkt innerhalb der Chat-Konversation im neuland.ai HUB.

### Zugriff und Nutzung

Um das Code & Data Analyst zu verwenden, öffnen Sie zunächst einen Chat und wählen Sie das Tool aktiv in der Tool-Leiste an. Anschließend können Sie Daten entweder direkt im Chat eingeben oder Dateien hochladen, mit denen die KI arbeiten soll.

Nach dem Upload kann die KI beispielsweise:

- Inhalte analysieren
- Daten extrahieren
- Informationen strukturieren
- Ergebnisse zusammenfassen oder in Grafiken visualisieren

Das Tool arbeitet vollständig innerhalb des Chat-Interfaces, nutzt eine sogenannte „Sandbox“ (gesicherte Umgebung) zur Codeausführung und erfordert keine zusätzliche Software.

### Code im Chat verwenden

Code oder strukturierte Daten können im Chat über sogenannte Codeblöcke dargestellt werden. Diese sorgen für eine übersichtliche Darstellung und erleichtern die Arbeit mit technischen Inhalten oder Datensätzen.

Ein Codeblock wird im Chat automatisch formatiert und mit Syntax-Highlighting angezeigt. Dadurch können Code, Abfragen oder strukturierte Daten klar dargestellt und gemeinsam mit der KI analysiert werden.

Codeblöcke dienen dabei nicht nur zur Darstellung von Code, sondern auch zur strukturierten Arbeit mit Daten innerhalb des Chats.

### Dateien und Daten hochladen

Der Code & Data Analyst unterstützt auch die Arbeit mit hochgeladenen Dateien. Diese können per Drag & Drop direkt in den Chat gezogen oder über die Upload-Funktion hinzugefügt werden.

Nach dem Upload kann die KI die Inhalte analysieren und für weitere Auswertungen nutzen. Typische

Datenquellen sind beispielsweise:

- Tabellen oder Datensätze
- Dokumente mit strukturierten Informationen
- Textdateien
- Exportierte Daten aus anderen Systemen

Die KI kann daraus relevante Inhalte extrahieren und in strukturierter Form darstellen.

Bitte beachten Sie etwaige Größenbegrenzungen der Dokumente, geben Sie der KI nur relevante Inhalte mit.

Die maximale Datengröße hängt vor allem von den enthaltenen Inhalten ab (nur Text, Text mit Tabellen, Bilder in PowerPoints etc., statt von der reinen Dateigröße. Sollte der neuland.ai HUB hier in Grenzen laufen, wird dies als Fehlermeldung kommuniziert, sodass die Dateien bei Bedarf unterteilt oder runterskaliert werden.

### Daten analysieren und strukturieren

Sobald Daten im Chat in den Datenquellen vorhanden sind, kann die KI diese analysieren und aufbereiten. Dazu können Sie der KI konkrete Anweisungen geben, beispielsweise:

- „Analysiere die hochgeladene Tabelle und zeige die wichtigsten Trends.“
- „Extrahiere alle relevanten Kennzahlen aus dem Dokument und stelle sie als Tabelle dar.“

Auf Basis dieser Anfragen erstellt die KI strukturierte Auswertungen und fasst die Ergebnisse übersichtlich zusammen.

### Ergebnisse erzeugen und exportieren

Ein zentraler Vorteil des Code & Data Analysts ist die Möglichkeit, aus den analysierten Daten strukturierte Ergebnisse und Dateien zu erzeugen. Die KI kann beispielsweise:

- Tabellen erstellen/Diagramme generieren
- strukturierte Datensammlungen aufbereiten
- Dateien zum Download erzeugen

#### Beispiel:

_Prompt:_ „Erstelle aus den Daten eine Tabelle mit den monatlichen Umsätzen.“

Die KI erstellt daraufhin eine strukturierte Übersicht und kann diese bei Bedarf auch als Datei bereitstellen.

### Typischer Ablauf

Ein häufiger Ablauf bei der Arbeit mit dem Code & Data Tool sieht folgendermaßen aus:

- Datei hochladen oder Daten im Chat bereitstellen
- Analyse oder Auswertung durch die KI anfordern
- Ergebnisse strukturieren lassen
- Ausgabe als Tabelle, Diagramm oder Datei erzeugen

Auf diese Weise können Daten schnell und direkt im Chat ausgewertet und weiterverarbeitet werden.

<Tip>
  **Hinweise zur Nutzung**

  Für optimale Ergebnisse empfiehlt es sich, die Daten möglichst klar zu beschreiben und konkrete Analyseziele zu formulieren. Strukturierte Daten, beispielsweise Tabellen oder Listen, erleichtern der KI zusätzlich die Verarbeitung.
</Tip>

Der Code & Data Analyst eignet sich besonders für Aufgaben wie das Erkennen von Trends, das Berechnen von Kennzahlen oder das Zusammenfassen von Datenmengen.

Alle Analysen und Ausgaben werden direkt innerhalb des neuland.ai HUB erstellt und können anschließend weiterverwendet oder exportiert werden.
