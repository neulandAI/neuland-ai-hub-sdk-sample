## Configure the client

<CodeGroup>

```python Python
from neuland_nimbus import Configuration, ApiClient

config = Configuration(host="https://api.your-domain.com")
config.api_key["APIKeyHeader"] = "ak.<key_id>.<secret>"  # sent as X-API-KEY
client = ApiClient(config)
```

```typescript TypeScript
import { Configuration, DefaultApi } from "@neuland/nimbus";

const api = new DefaultApi(
  new Configuration({
    basePath: "https://api.your-domain.com",
    apiKey: "ak.<key_id>.<secret>",  // sent as X-API-KEY
  }),
);
```

</CodeGroup>

## Make a request

Method names are derived from each endpoint's `operationId` (with the
resource prefix stripped), so `GET /users/me` becomes `users.me()` /
`getMe()` depending on the target language.

```python Python
from neuland_nimbus.api.user_api import UserApi

me = UserApi(client).me()
print(me)
```
