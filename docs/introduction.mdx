The **Neuland AI Hub API** powers chat, retrieval-augmented document Q&A,
assistants, and the surrounding workspace, tenant, and integration features of
the platform.

You can use the API in two ways:

<CardGroup cols={2}>
  <Card title="REST API" icon="server" href="/quickstart">
    Call the HTTP endpoints directly from any language. Browse every endpoint
    in the <b>API Reference</b> tab.
  </Card>
  <Card title="SDK" icon="cube" href="/installation">
    Use the generated client library for typed requests and responses.
  </Card>
</CardGroup>

## Base URL

```
https://api.your-domain.com
```

## Authentication

Most endpoints require an API key sent in the `X-API-KEY` header. See
[Authentication](/authentication) for details.
