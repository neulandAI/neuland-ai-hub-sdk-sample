### Was ist das Web-Search Tool?

Das Web-Search Tool ermöglicht gezielte Recherchen im Internet direkt aus dem Chat des neuland.ai HUB heraus. Damit können Sie aktuelle Informationen, Trends oder externe Fakten abrufen, ohne die Plattform verlassen zu müssen. Die Ergebnisse werden kompakt zusammengefasst.

Bitte beachten Sie, dass das Web-Search Tool externe Quellen einbindet. Für die Recherche wird dabei Perplexity verwendet, das speziell für strukturierte Webabfragen mit transparenten Quellen entwickelt wurde.

Das Web-Search Tool wird genauso wie das Deep Search Tool oder auch das Reasoning von Ihrer Unternehmung freigeschaltet. Perplexity ist als Tool DSGVO-konform und darf ebenfalls keine Daten speichern oder diese verwenden, wird jedoch als einiges Tool über amerikanische Server geleitet.

### **Nutzung des Web-Search Tools**

Die Nutzung erfolgt direkt innerhalb eines Chats im neuland.ai HUB:

1. Öffnen Sie einen neuen Chat.
2. Wählen Sie im Chatfenster unter Tools den Web-Search Agenten aus, in dem Sie diesen Anwählen3.Formulieren Sie Ihre Suchanfrage im Chat-Fenster mit aktiviertem Tool, beispielsweise: „Aktuelle Trends im E-Commerce 2026“.
3. Das Tool recherchiert passende Inhalte im Internet und erstellt eine kurze Zusammenfassung mit Quellenangaben.

Standardmäßig sind die Antworten bewusst kompakt gehalten, um einen schnellen Überblick zu ermöglichen.

### Tipps für bessere Ergebnisse

Wenn Sie eine ausführlichere Analyse wünschen, können Sie dies direkt im Prompt ergänzen, zum Beispiel:

- „Bitte ausführlich beantworten.“
- „Bitte mit URL der Quellen angeben.“

Auf diese Weise können Sie die Detailtiefe der Antwort steuern oder sich die exakten Links zu den verwendeten Quellen anzeigen lassen.

### Beispielanfragen

**<u>Beispiel 1 – Kurze Recherche</u>**

**Prompt:** „Was sind die wichtigsten Neuerungen im Datenschutzrecht 2026?“

**Beispielantwort:** Die wichtigsten Neuerungen im Datenschutzrecht 2026 betreffen unter anderem Anpassungen im Zusammenhang mit dem EU Digital Services Act (DSA), neue Meldepflichten für Unternehmen sowie erweiterte Betroffenenrechte.

**Quellen:** \[Name der Quelle\]

**<u>Beispiel 1 – Ausführliche Recherche mit URLs</u>**

**Prompt:** „Bitte nenne mir ausführlich die aktuellen Trends im Online-Marketing 2026 und gib die URLs der Quellen an.“

**Beispielantwort:** Zu den wichtigen Trends im Online-Marketing 2026 zählen KI-gestützte Personalisierung, Voice-Search-Optimierung sowie nachhaltige Marketingstrategien.

**Quellen:** • Marketing Magazin • Online Marketing Blog

<Tip>
  **Hinweise zur Nutzung**

  Das Tool liefert standardmäßig kompakte Antworten. Für mehr Details können Sie dies im Prompt anfordern. Quellen werden immer genannt, URLs können bei Bedarf explizit angefordert werden. Nach der Recherche können Sie den Web-Search Agenten wieder deaktivieren und wie gewohnt im geschützten Chat weiterarbeiten.
</Tip>
